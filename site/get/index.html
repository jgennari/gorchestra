Threave runs on your own machine and opens in your browser. Install it, connect the coding agents you already use, and keep your work moving in one place.

Install Threave

Homebrew is the fastest path on macOS. Release archives are available for macOS, Linux, and Windows.

MACOS / HOMEBREW

Install, then open your workspace

brew install threave-io/tap/threave threave serve --open

Threave serves its interface locally. The agents you use need to be installed and available on your machine.

OTHER PLATFORMS

Download a release

Choose the archive for your system, unpack it, and run threave serve --open. Each release includes the app and its frontend in one executable.
